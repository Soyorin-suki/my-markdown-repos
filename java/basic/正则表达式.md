# 正则表达式(Regular Expression)
参考 https://zhuanlan.zhihu.com/p/655706221

一般简称为regex.

## 1. 元字符

|元字符|描述|
|---|---|
.|匹配除换行符以外的任意单个字符|
[]|匹配括号内的任意一个字符|
[^]|匹配不在括号内的任意一个字符|
*|匹配前一个字符零次或多次|
+|匹配前一个字符一次或多次|
?|匹配前一个字符零次或一次|
{n}|匹配前一个字符恰好n次|
{n,}|匹配前一个字符至少n次|
{n,m}|匹配前一个字符至少n次但不超过m次|
(xyz)|字符组，按照顺序进行匹配|
|^|匹配字符串的开始|
|$|匹配字符串的结束|
\||匹配左右任意一个表达式|
\\ |转义字符，匹配特殊字符本身|


## 2. 简写字符集
|简写字符集|描述|
|---|---|
|.|匹配除换行符以外的任意单个字符|
|\d|匹配任意一个数字字符，等价于[0-9]|
|\D|匹配任意一个非数字字符，等价于[^0-9]|
|\w|匹配任意一个字母、数字或下划线字符，等价于[a-zA-Z0-9_]|
|\W|匹配任意一个非字母、数字或下划线字符，等价于[^a-zA-Z0-9_]|
|\s|匹配任意一个空白字符，包括空格、制表符、换行符等，等价于[ \t\n\r\f\v]|
|\S|匹配任意一个非空白字符，等价于[^ \t\n\r\f\v]|

## 3. 断言
先行断言与后行断言被称为断言，用于匹配模式而非文本。
|断言|描述|
|---|---|
?=|正向先行断言，匹配某个模式后面紧跟着的文本|
?!|负向先行断言，匹配某个模式后面不紧跟着的文本|
?<=|正向后行断言，匹配某个模式前面紧跟着的文本|
?<!|负向后行断言，匹配某个模式前面不紧跟着的文本|

## 5. 在java中使用正则表达式
在Java中，正则表达式是通过java.util.regex包中的Pattern和Matcher类来实现的。

也可以通过String类中的matches()、replaceAll()、split()等方法来使用正则表达式。

e.g.
```java
String s = "18811112222";	// 这是一个电话号码
String regex = "^1[3-9]\\d{9}$";	// 这是一个匹配中国大陆电话号码的正则表达式
boolean isMatch = s.matches(regex);	// 使用String类的matches方法来判断是否
```
