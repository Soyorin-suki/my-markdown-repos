# 区块链

## 什么是区块链
区块链，本质上是一种分布式数据库技术。广义来说，是一个点对点的动态网络，与传统的集中式不同，每个节点可以提供服务也可以请求服务，可以随时有新节点加入或旧节点退出。

狭义来说，区块链是种**按照时间顺序**将数据区块以顺序相连的方式组合成的一种**链式数据结构**并以**密码**科学方式保证**不可篡改**和**不可伪造**的分布式账本。

区块链是一个分布式账本，通过去中心化、去信任的方式维护一个数据库。
- 从数据上来看：区块链是一种几乎不可能被更改的分布式数据库。这里的“分布式”不仅体现为数据的分布式存储，也体现为数据的分布式记录（即由系统参与者共同维护）
- 从技术上来说：区块链并不是一种单一的技术，而是多种技术整合的结果。

## 区块链的特征：
- 开放，共识
- 去中心、去信任
- 交易透明，双方匿名
- 不可篡改，可追溯

## 区块链的分类
1. 公有区块链(Public Blockchain, 公有链)：任何人都可以参与的区块链网络，具有完全的去中心化特征。
   - 三个主要特点：
   1. 公有链的程序开发者不能干涉用户，用户权益能够得到保障
   2. 开放性更强，任何用户都可以在其之上开发应用
   3. 数据完全公开透明，不过由于用户匿名，数据的隐私性得到保障
2. 私有区块链(Private Blockchain, 私有链)：由一个组织或公司控制的区块链网络，参与者需要获得许可才能加入。
3. 联合区块链(Consortium Blockchain, 联盟链)：由多个组织或公司共同控制的区块链网络，参与者需要获得许可才能加入。

## 数据结构
区块链以区块为单位组织数据，全网所有的交易记录都以交易单的形式存储在全网唯一的区块链中

一个区块包含区块头和区块体两部分，区块头包含头信息(上一个区块的哈希值、本区块体的哈希值、时间戳等)，区块体包含交易记录等数据。

区块的形成过程：
略

所有区块通过previous hash或next hash连接成链式结构，保证了区块链的不可篡改性和可追溯性。

工作流程：
1. 交易发生
2. 全网节点监听交易记录
3. 验证记录并放入内存
4. "算出"区块并广播全网共识
5. 共识后新的区块被纳入区块链存储，回到2

## 区块链基础架构
- 应用层(实现转账和记账功能)
- 激励层(发行机制和分配机制)
- 共识层(POW)
- 网络层(p2p网络, 传播机制, 验证机制)
- 数据层(区块数据, 链式结构, 数字签名, merkle树等)

### 激励层
激励层将经济因素集成到区块链技术体系中来，主要包括经济激励的发行机制和分配机制等。
- 发行机制，所有的比特币将通过奖励给创建了新区块的矿工的方式产生，每四年奖励减半，直到2100万枚比特币被挖完。
- 交易费：所有交易都需要支付交易费，矿工优先处理交易费较高的交易。

### 共识层
- 工作量证明机制(Proof of Work, POW)：通过计算大量的哈希值来竞争记账权，消耗大量的计算资源和电力。
- 双花问题：同一笔数字货币被多次使用，解决方法是通过共识机制来确认交易的唯一性。
- 为什么区块链每10min发布一次：间隔时间越短，资源浪费越大，网络延迟造成的影响越大，容易形成**分叉**

p2p网络提供了耐攻击、高容错的网络环境。
