## 对数据与服务的安全目标
|||确保|防止|
|---|---|---|---|
|保密性|Confidentiality|数据保密性，隐私性|信息的非授权泄漏|
|完整性|Integrity|数据完整性，系统完整性|对信息的非授权修改和毁坏|
|可用性|Availability|确保系统能够正确响应服务请求|对系统访问和使用的中断|
|真实性|Authenticity|确保通信双方的身份和信息的来源||
|可审计性|Accountability|确保系统能够记录和追踪用户的行为|对系统的滥用和攻击||


## OSI安全架构
- ITU是最权威、最广泛的通信标准化组织。
- 特点：标准制定过程公开、公正、标准体系完整。
- OSI(Open Systems Interconnection)模型是国际标准化组织(ISO)制定的网络通信框架结构，是网络互联的基础。
- X.800是OSI安全架构的核心标准，定义了安全攻击、安全机制和安全服务的概念和分类。
  
主要关注三个方面的内容：
- 安全攻击：任何威胁系统安全的行为或事件。
- 安全机制：用来检测、阻止攻击或恢复到正常。
- 安全服务：为加强系统的安全性，利用一种或多种安全机制抵制安全攻击的服务。

### 安全攻击
||目标|分类|特点|
|---|---|---|---|
|被动攻击|攻击者的目标是获取和利用系统的信息，但不影响系统资源|信息的泄露；流量分析|危害小，难以被察觉|
|主动攻击|试图改变系统资源或影响系统运行|伪装攻击；重放攻击；修改攻击；拒绝服务攻击|危害大，容易被发现从而进行防御|

### 安全服务
安全服务是一种由系统提供的对系统资源进行特殊保护的处理或通信服务。
X.800定义了以下安全服务：
1. 认证服务(Authentication Service) - 保证通信的实体是它所声称的实体
2. 访问控制服务(Access Control Service) - 阻止对资源的非授权使用
3. 数据保密性服务(Data Confidentiality Service) - 确保数据在传输过程中不被泄露
4. 数据完整性服务(Data Integrity Service) - 确保数据在传输过程中未被修改
5. 不可否认服务(Non-repudiation Service) - 确保通信的双方不能否认他们的行为
